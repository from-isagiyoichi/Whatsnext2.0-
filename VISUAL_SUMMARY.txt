  OPTION 2: Deploy to Render.com (10 minutes)
  ═══════════════════════════════════════════
    1. Sign up at render.com
    2. Create Web Service → Connect GitHub
    3. Build: cd flask-backend && pip install -r requirements.txt
    4. Start: cd flask-backend && gunicorn app:app
    5. Add PostgreSQL database
    6. Set environment variables
    7. Deploy!
    8. Update React with your API URL

┌──────────────────────────────────────────────────────────────────────────────┐
│  🔧  CONFIGURATION                                                           │
└──────────────────────────────────────────────────────────────────────────────┘

  TO ENABLE FLASK BACKEND:
  ════════════════════════
  
  Update 4 files in /src/app/services/:
  
    1. authService.ts
    2. eventService.ts  
    3. bookingService.ts
    4. notificationService.ts
  
  In each file, change:
  
    private static BASE_URL = "https://your-api-url.com/api";
    private static USE_MOCK = false;
  
  TO GO BACK TO MOCK MODE:
  ════════════════════════
  
    Set USE_MOCK = true in all 4 files above


┌──────────────────────────────────────────────────────────────────────────────┐
│  🌐  API ENDPOINTS                                                           │
└──────────────────────────────────────────────────────────────────────────────┘

  Authentication:
    POST   /api/auth/login              User login
    GET    /api/auth/validate           Validate token

  Events:
    GET    /api/events                  List all events
    GET    /api/events/:id              Get event details

  Bookings:
    POST   /api/bookings                Create booking
    GET    /api/bookings                List user bookings
    DELETE /api/bookings/:id            Cancel booking

  Notifications:
    GET    /api/notifications           List notifications
    PUT    /api/notifications/:id/read  Mark as read
    GET    /api/notifications/unread-count  Get unread count

  User Profile:
    GET    /api/user/profile            Get profile
    PUT    /api/user/profile            Update profile

  Health:
    GET    /api/health                  Health check

│  🛠️  TROUBLESHOOTING                                                         │
└──────────────────────────────────────────────────────────────────────────────┘

  Problem: Backend won't start
  Solution: Check if student-list.txt exists in flask-backend/

  Problem: CORS errors in browser
  Solution: Verify Flask-CORS is installed and CORS(app) is called

  Problem: Database connection error
  Solution: Check DATABASE_URL environment variable

  Problem: Invalid credentials
  Solution: Run verify_students.py to check student-list.txt format
