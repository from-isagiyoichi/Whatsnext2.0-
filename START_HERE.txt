PATH 1: Local Testing First (Recommended)
═══════════════════════════════════════════════════════

⏱️  Time: 5-10 minutes
📚  Difficulty: Easy

Steps:
  1. cd flask-backend
  2. pip install -r requirements.txt
  3. cp ../src/imports/student-list.txt ./
  4. python app.py
  5. Visit: http://localhost:5000/api/health
  6. Update React: USE_MOCK = false, BASE_URL = "http://localhost:5000/api"
  7. Test login with: ajgayathrinair.b25ee1101@mbcet.ac.in / AjGa01_EE

Why this path?
  ✅ Test everything locally first
  ✅ Easier to debug
  ✅ No cloud account needed yet
  ✅ See logs in real-time


PATH 2: Deploy to Render.com Directly
═══════════════════════════════════════════════════════

⏱️  Time: 15-20 minutes
📚  Difficulty: Medium

Steps:
  1. Sign up at https://render.com
  2. New → Web Service
  3. Connect GitHub or upload files
  4. Configure:
       Build: cd flask-backend && pip install -r requirements.txt
       Start: cd flask-backend && gunicorn app:app
  5. Add PostgreSQL database
  6. Set environment variables:
       SECRET_KEY=your-random-secret
       FLASK_ENV=production
  7. Upload student-list.txt
  8. Deploy!
  9. Get URL: https://yourapp.onrender.com
  10. Update React with your URL

Why this path?
  ✅ Production-ready immediately
  ✅ Free PostgreSQL database
  ✅ Automatic HTTPS
  ✅ No server maintenance


PATH 3: Deploy to Railway.app
═══════════════════════════════════════════════════════

⏱️  Time: 10-15 minutes
📚  Difficulty: Easy

Steps:
  1. Sign up at https://railway.app
  2. New Project → Deploy from GitHub
  3. Add PostgreSQL (auto-configured)
  4. Set environment variables
  5. Railway auto-detects Python
  6. Deploy automatically
  7. Get your URL from dashboard
  8. Update React services

Why this path?
  ✅ Fastest deployment
  ✅ Auto-configuration
  ✅ Simple interface
  ✅ Good free tier

  📄 /src/app/services/notificationService.ts

In each file, find and change:

  FROM:
    private static BASE_URL = "http://localhost:5000/api";
    private static USE_MOCK = true;

  TO:
    private static BASE_URL = "https://your-api-url.com/api";
    private static USE_MOCK = false;

1. Student List Required
   • Copy student-list.txt to flask-backend/
   • Format: email, password (alternating lines)
   • Run verify_students.py to check

2. Environment Variables
   • Set SECRET_KEY (random string)
   • Set DATABASE_URL (auto for Render/Railway)
   • Set FLASK_ENV=production

3. Figma Make Limitation
   • Cannot run Python servers
   • Flask must be deployed separately
   • React connects via REST API

4. Current Mode
   • App works in MOCK mode (localStorage)
   • Safe to test everything
   • Switch when backend is ready
